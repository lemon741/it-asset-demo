# IT資産管理（デモ版）

社内の IT 機器（PC・携帯・SIM など）の貸し出し状況を管理するアプリの、**サーバー不要の公開用デモ版**です。
URL を知っていれば、誰でも・どこからでもブラウザで開けます。

## しくみ

| | 社内版 | このデモ版 |
|---|---|---|
| 画面 | Flask + HTML | 同じ HTML（`index.html`） |
| データ | 社内の MySQL | ブラウザ内（localStorage）。サンプルデータ（すべて架空） |
| 動かす場所 | 社内サーバー | GitHub Pages（静的ファイルだけ） |

`mock-api.js` が、社内版のサーバー（`/api/...`）と同じ動きをブラウザの中で再現しています。
そのため、ログイン・機器の状態変更・社員/SIM/状態の管理・CSV一括登録・メッセージなど、画面の機能はほぼそのまま試せます。

- 変更内容は**各自のブラウザの中だけ**に保存されます（他の人には見えません・共有されません）。
- ログイン画面の「初期状態に戻す」で、サンプルデータをいつでもリセットできます。
- 管理者の操作を試すときは「佐藤 美咲」または「鈴木 健太」でログインしてください。

## GitHub Pages で公開する手順

1. GitHub で新しいリポジトリを作る（例: `it-asset-demo`）。公開（Public）にします。
2. このフォルダの中身（`index.html` / `mock-api.js` / `.nojekyll` / `README.md`）をアップロードする。
   - 「Add file → Upload files」にドラッグ＆ドロップ → 「Commit changes」。
3. リポジトリの **Settings → Pages** を開く。
   - **Source**: `Deploy from a branch`
   - **Branch**: `main` / `/ (root)` → **Save**
4. 1〜2分待つと、次の URL で見られます。

   `https://（GitHubのユーザー名）.github.io/（リポジトリ名）/`

この URL を共有すれば、誰でも開けます。

## ⚠ 公開してはいけないもの

社内版のファイル（`app.py` / `setup_db.py` / `inspect_db.py` / `migrate_from_sheet.py` / `schema.sql`）には、
**DB のホスト名・ユーザー名・パスワード、スプレッドシートの URL** が書かれています。
これらは公開リポジトリに**アップロードしないでください**（`.gitignore` にも入れてあります）。
もし過去に外部へ貼り付けた場合は、DB のパスワードを変更することをおすすめします。

## ファイル

- `index.html` … 画面（会社ロゴ・社名は削除済み）
- `mock-api.js` … ブラウザ内の簡易サーバー＋架空のサンプルデータ
- `.nojekyll` … GitHub Pages がそのまま配信するための空ファイル
